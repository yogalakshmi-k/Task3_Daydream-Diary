## 🌸 About the Project

**Daydream Diary** is a cute, aesthetic journaling and to-do list web application designed to make everyday planning more enjoyable.

With a soft peach, baby pink, sage green and cream colour palette, it combines daily journaling, mood tracking and task management in one cozy digital space.

## ✨ Features

- 📝 **Daily Journaling** — Write and save personal thoughts and memories.
- 😊 **Mood Tracker** — Select your mood for each journal entry.
- 📌 **Task Management** — Add daily tasks easily.
- ☑️ **Task Completion** — Mark completed tasks.
- 🗑️ **Delete Tasks** — Remove unwanted tasks.
- 🌱 **Progress Tracker** — Track your daily task completion.
- 💾 **Local Storage** — Save tasks and journal entries even after refreshing the browser.
- 📱 **Responsive Design** — Works on desktop, tablet and mobile screens.

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Alternatively, use the Live Server extension in VS Code.
